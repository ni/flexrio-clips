Offset 0x0008: OldestCompatReg Register (R)

(show extended info)
OldestCompatReg
  offset=0x0008

Initial Value not specified

This register is defined in HDL source file StandardRegs.vhd.

Specifies the oldest Revision Register value for which the current register map is still compatible.
BitsName
31..0

OldestCompatData

OldestCompat is a BCD formatted build date which indicates the oldest FPGA version that had a register set compatible with the current version. This allows software that is older than this version of the FPGA to decide if it can correctly control the FPGA. If the driver software was designed for any FPGA build date equal to or later than the oldest compatible date, the software should operate correctly on this FPGA. If the driver software was designed for any FPGA build date prior to the oldest compatible date, the software should terminate with a useful incompatibility message.
Typically, the current version of the register map must be a strict superset of its oldest compatible build date and the new features must be optional. In some cases, a design update might make a writable register optional. In that case old software might write a non-existent register but if the new FPGA still operates correctly, it could maintain the same oldest compatible date.
The OldestCompatData returns the date in the format: 0xYYMMDDHH
OldestCompatData: 0x18052309

IoSocketAxiBridgeRegs

Regmap Organization

This regmap implements a reset-domain-crossing interface between the Fixed Logic (FL) MicroBlaze (uB) and the Io Module CLIP (CLIP). The registers are implemented in 3 general categories:
  1. FixedLogicToClipRam - Communicates data from the FL uB to the CLIP via a memory element.
  2. ClipToFixedLogicRegs - Communicates data from the CLIP to the FL uB.
  3. BridgeSharedKnowledge - Communicates data from elsewhere in the board to both the FL uB and the CLIP.

The register ranges for each of these categories are defined in AxiBridgeRangesEnum.

FixedLogicToClipRam

These registers are implemented in a LUT RAM driven by the FixedLogic. They persist reset and are used to pass semi-constant or information that is rarely updated to the CLIP. Despite these registers being marked as read/write, they are Read-Only for the Clip, and write-only for the FixedLogic.

The address range for this group is from defined in AxiBridgeRangesEnum
